# liyown Homebrew tap

Install Memvault on macOS or Linux:

```sh
brew install liyown/tap/memvault
memvault version
```

Upgrade with `brew update && brew upgrade liyown/tap/memvault`.

Formulae use the prebuilt archives and SHA-256 checksums from
[liyown/memvault releases](https://github.com/liyown/memvault/releases).
The Memvault Release workflow updates `Formula/memvault.rb` after each stable
release using a deploy key scoped to this repository.
